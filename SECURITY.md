# Security Policy

## Supported Versions
Security updates are provided for the following versions:
| Version | Supported |
| :--- | :--- |
| MVP Release (Phase 4) | Yes |
| Pre-release alphas | No |

## Reporting a Vulnerability
Please report security vulnerabilities locally to developers or via private project communication channels. Do not open public GitHub issues for security reports. We aim to respond within 48 hours to coordinate a secure release fix.
